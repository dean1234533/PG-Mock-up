# Da Gym London Stratford: multi-page gym website mockup

**A multi-page website concept for a gym brand with several branches. It centres on a Stratford location page, with memberships, classes, personal trainers, and a gym finder.**

> gym chain's website, with a local landing page for each branch to support
> local SEO.

## Features

- A **location landing page** for London Stratford covering what's inside,
  classes, and how to find the gym
- **Memberships** page with plan comparison
- **Classes** and **personal trainers** pages
- A **"Find a gym"** branch finder
- About, privacy, and terms pages
- A responsive, mobile-first layout

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html, gym-london-stratford.html, memberships.html, classes.html
personal-trainers.html, find-a-gym.html, about.html, privacy.html, terms.html
css/main.css, js/main.js
```

## Run locally

```bash
git clone https://github.com/dean1234533/PG-Mock-up.git
cd PG-Mock-up
open index.html
```
